# Notice

Sail is a Cascades interface around a third-party browser engine. The interface and integration code in this repository are MIT-licensed (see LICENSE). The engine is not part of this repository.

## Browser engine

Sail's engine is **Chromium for BB10** by sw7ft, the `berry-v3` branch (content shell port).

- Source: https://github.com/sw7ft/chromium-for-bb10 (branch `berry-v3`)
- Chromium is licensed under the BSD 3-Clause licence.

The author granted permission to distribute Sail built on `berry-v3`, with credit and a link back, in https://github.com/sw7ft/chromium-for-bb10/issues/7. If the author changes those terms, the new terms apply.

The credit is shown in the app under Settings, "About & engine credit".

## Other components

- `engine/gcc9/`: BlackBerry 10 toolchain builder (gcc 9.3.0) from https://didacticode.ca/blog/development-tools-for-blackberry-10, kept with its original README.
- Interface icons: rendered from Tabler Icons (MIT), https://tabler.io/icons.
